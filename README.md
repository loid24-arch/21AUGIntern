# Intern-Veri.

Project for the 21 August 2026 Hackathon.

## Project Structure

- frontend - Frontend application
- backend - Backend/API
- docs - Project documentation
## Internship Lifecycle Additions
- Search internships by role/company/skill, location and work mode.
- Internship details modal and bookmark flow.
- Application timeline and withdrawal action.
- Student tracker for attendance, deadlines, milestones and completion workflow.
- Daily-report leaderboard (10 points per report + 5 review bonus).
- Internship document registry: offer/joining/completion/attendance/evidence records.
- Teacher review and T&P verification endpoints for internship documents.
